## 🔑 Key Project
**Bank Churn Prediction** (`Binary_Classification_Using_ANN.ipynb`) — predicts customer churn from 10,000 banking records. Architecture: Dense(11,relu)→Dense(11,relu)→Dense(1,sigmoid), compiled with Adam + binary_crossentropy.
